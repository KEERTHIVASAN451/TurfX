# 🏏 TurfX - Smart Turf & Cricket Tournament Management System

TurfX is a complete web application built using **Python (Flask)** for managing cricket turf bookings and tournaments. It provides separate dashboards for **Admin**, **User**, and **Tournament Organizer** with real-time booking, payments, scorecards, and tournament management.
